# MATRIX Breast Cancer Detection System  
### YOLOv8 + Tkinter | Mammogram Image Tumor Detection  

*A futuristic Matrix-themed AI tool for breast cancer tumor detection using YOLOv8 deep learning.*

---

## Overview

This project is a **desktop-based breast cancer detection system** built using **YOLOv8** and a **Matrix-style Tkinter GUI**.  
It allows users to:

- upload  mammogram images  .
- Automatically detect **tumor / normal regions**  
- View annotated YOLO results  
- Check confidence percentages  
- Run a **live webcam YOLO demo**  
- Monitor real-time system logs  

*This is for educational & research purposes only — NOT a medical diagnostic tool.*
